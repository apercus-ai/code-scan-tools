# /code-scan-fix

在 `/code-scan` 完成之后使用。用户挑选要修的发现(按 id 或 `where` 描述),逐个修复并开 PR。

## 步骤

1. 从最近一次扫描的完成通知/报告中取出选中的发现(找不到就让用户贴出来)。
2. 对每条发现:
   - 确认仓库(克隆副本在 `.code-scan/repos/<name>`,或用户指定的本地仓库)
   - 创建分支 `code-scan/fix-<短slug>`
   - 只做该发现描述的最小修复,不顺手重构
   - 能跑测试就跑;跑不了在 PR 描述里注明
   - 用 `gh` 开 PR,描述包含:问题、证据、修法、测试结果、来源发现 id
3. 每条发现一个 PR(默认);用户明确要求合并成一个 PR 才合并。
4. 不要自动 merge;PR 交人工审查。

## 安全

- 只改选中的问题;不碰无关文件
- 不 force-push;不动用户已有分支
- 若修复需要改依赖或大范围重构,先停下来问用户
